# 🐱 Кото-Кликер: Мурр-Магнат (Cat Tycoon) для Яндекс Игр

Готовая к публикации HTML5-игра в жанре **Кликер / Idle Tycoon** с полной интеграцией **Yandex Games SDK v2**.

---

## 🎮 Особенности игры

1. **Геймплей и механики:**
   - Тапы по анимированному котику с плавающими цифрами дохода и шансом на **критический урон (КРИТ)**.
   - **Улучшения клика:** Острые коготки, Лазерная указка, Заводная мышка, Золотая лапка, Кибер-перчатка, Квантовый тык.
   - **Пассивный бизнес (доход в секунду):** Клубок пряжи, Мята, Авто-кормушка, Когтеточка, Рыбный рынок, Кото-кафе, Отель, Банк, Космическая станция, Мурр-Галактика.
   - **Случайное событие «Золотая Мышка»:** Периодически пролетает через экран — при клике активирует режим **🔥 ФРЕНЗИ (x7 ко всем доходам на 30 секунд)**.
   - **Оффлайн-доход:** Пока игрока нет в игре, котики продолжают зарабатывать монеты (до 8 часов). При входе игрок может забрать обычную сумму или **утроить (x3) за просмотр рекламы**.
   - **Система перерождений («Кошачья Нирвана» / Prestige):** Сброс прогресса в обмен на Звёзды Нирваны (+15% к доходу за каждую звезду навсегда).
   - **Гардероб и скины:** Классический рыжик, Кот-Босс, Кибер-Кот, Царь-Кот, Космо-Кот (с очками, короной, визором и скафандром).
   - **10 игровых достижений** с наградами в монетах.

2. **Интеграция с Яндекс Играми (Yandex Games SDK v2):**
   - **Межстраничная реклама (Fullscreen Adv):** Встроена с защитой от спама и кулдауном.
   - **Реклама за вознаграждение (Rewarded Video):** Удвоение дохода на 3 минуты, Мега-сундук с монетами, утроение оффлайн-дохода.
   - **Облачные сохранения (Cloud Saves):** Сохранение в профиль Яндекс Игрока через `player.setData()` с автоматическим переключением на `localStorage` при локальном тестировании.
   - **Таблица лидеров (Leaderboard):** Рейтинг лучших игроков по заработанным монетам (`top_coins`).
   - **Звук и фокус:** Синтез звуков через Web Audio API (без внешних тяжёлых mp3). Звук автоматически глушится при показе рекламы и при сворачивании вкладки браузера (`visibilitychange`).
   - **Адаптивность:** Полная поддержка ПК (мышь, пробел) и мобильных телефонов (тач-мультитач без задержек и зума).

## 📁 Структура проекта

- `index.html` — главная страница и структура интерфейса.
- `style.css` — стили, анимации, адаптивная верстка (мобильные/десктоп).
- `game.js` — игровая логика, баланс, формулы дохода, скины и достижения.
- `yandex-sdk.js` — модуль работы с Яндекс SDK v2 (реклама, облако, таблица лидеров, тестовый режим).
- `audio.js` — процедурный звуковой генератор (клики, монетки, френзи, фанфары).
- `particles.js` — эффекты конфетти, всплывающие цифры и искры.
- `icon.svg` — векторная иконка игры.
- `game.zip` — готовый архив для загрузки в консоль Яндекс Игр!

## 🚀 Как запустить и протестировать локально

1. Просто откройте файл `index.html` в любом браузере (Chrome, Яндекс Браузер, Edge, Firefox).
2. В локальном режиме игра автоматически переходит в **эмуляцию SDK (Mock Mode)**:
   - Все кнопки рекламы показывают красивое тестовое окно с таймером.
   - Прогресс сохраняется в `localStorage`.
   - Таблица лидеров отображает тестовые данные.
   - Вы можете нажимать пробел или кликать мышкой по котику.

## 🌐 Как опубликовать игру на Яндекс Играх

### Шаг 1: Регистрация в Консоли разработчика
1. Перейдите в [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console/).
2. Авторизуйтесь под своим Яндекс-аккаунтом.
3. Нажмите кнопку **«Добавить приложение»**.

### Шаг 2: Загрузка архива
1. В разделе **«Исходный код»** выберите файл `game.zip`.
2. Дождитесь проверки архива (система проверит наличие `index.html` в корне архива).

### Шаг 3: Настройка свойств игры
1. **Название:** `Кото-Кликер: Мурр-Магнат` (или своё).
2. **Категории:** `Казуальные`, `Кликеры`, `Симуляторы`.
3. **Возрастной рейтинг:** `0+`.
4. **Ориентация:** Поддерживаются обе (Вертикальная и Горизонтальная).
5. **Иконка и промо-материалы:**
   - Загрузите иконку 512x512 (можно использовать `icon.svg`).
   - Сделайте 2-3 скриншота игры.

### Шаг 4: Настройка таблицы лидеров
1. В консоли перейдите во вкладку **«Лидерборды»**.
2. Создайте новый лидерборд:
   - **Техническое имя:** `top_coins` (именно такое имя прописано в коде).
   - **Тип сортировки:** По убыванию (чем больше очков, тем выше место).
   - **Формат чисел:** Целое число.

### Шаг 5: Проверка и отправка на модерацию
1. Нажмите **«Черновик»** -> **«Проверить в песочнице»**.
2. Убедитесь, что:
   - Игра запускается без белых экранов.
   - Кнопки рекламы открывают реальную тестовую рекламу Яндекса.
   - Звук отключается при показе рекламы.
3. Нажмите кнопку **«Отправить на модерацию»**. Модерация обычно занимает от нескольких часов до 2-3 рабочих дней.

## 🛠️ Как изменить баланс или добавить улучшения

- Все улучшения клика настраиваются в файле `game.js` в массиве `clickUpgradeDefs`.
- Все пассивные улучшения настраиваются в массиве `idleUpgradeDefs`.
- Формула стоимости каждого улучшения: `baseCost * (costMult ^ уровень)`.
- Чтобы изменить коэффициент бонусов от рекламы или время Френзи, отредактируйте параметры `activateFrenzy(30)` или `activateAdDoubleBoost(180)`.
